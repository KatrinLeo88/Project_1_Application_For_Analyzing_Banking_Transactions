# Проект: Анализатор банковских операций

Приложение для анализа транзакций из Excel-файлов. Генерирует JSON-ответы для веб-страниц, формирует отчеты и предоставляет сервисы поиска.

## Функциональность

### 1. Веб-страницы (Views)
-   **Главная страница:** Отображает приветствие, сводку по картам, топ транзакций, курсы валют и стоимость акций.
-   Поддерживает фильтрацию данных по дате.

### 2. Сервисы (Services)
-   **Простой поиск:** Поиск транзакций по ключевому слову в описании или категории.

### 3. Отчеты (Reports)
-   **Траты по категории:** Формирует отчет о тратах в заданной категории за последние 3 месяца.
-   Автоматическое сохранение отчетов в JSON-файлы через декоратор.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/KatrinLeo88/homework.git
   ```

2. **Установите зависимости через Poetry:**
   ```bash
   poetry install
   ```

3. **Создайте файл .env** и добавьте API ключи (см. `.env.example`).

4. **Заполните настройки пользователя** в `user_settings.json`.

## Использование

Для демонстрации работы всех модулей запустите скрипт:
```bash
python -m src.main
```

## Тестирование

Проект покрыт тестами более чем на 80%. Используются фикстуры и моки для эмуляции внешних API.

Запуск тестов с отчетом о покрытии:
```bash
poetry run pytest --cov=src --cov-report=term-missing
```
